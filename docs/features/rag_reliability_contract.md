## Numbered requirements

F7 period binding uses each operand's attested user clause or reviewed source
clause/table row, with separate quote hashes and source offsets. It does not assign
the period union of the whole request or joined proof quotes. Incompatible periods,
multiple local periods and unlabelled table year ranges fail only the component and
its descendants; independent compatible arithmetic remains eligible after final
scope verification. The real registry/graph regression home is
[test_operand_period_binding.py](../../tests/unit/modules/conversations/test_operand_period_binding.py).
Formula publication accepts exact decimal value equivalence without rounding or
tolerance, preserves operator/operand order and numeric token boundaries, renders
the verified graph expression and requires final source/scope verification. The
same regression module exercises this actual finalizer boundary with valid controls,
changed-value/long-precision negatives and independent rule retention.
Current-source full quality and live acceptance remain separate gates.

The wrapped-quantity boundary preserves the entire attested number-and-scale span
across whitespace line wraps without joining unrelated clauses. Its paired source,
user, finalizer and persisted-transport regressions are in
[wrapped quantity binding](../../tests/unit/modules/conversations/test_wrapped_quantity_binding.py).
C1/C2 review copies preserve nested omission and stored authenticated provenance;
explicit new review metadata cannot override server source/target/reviewer identities
or reason. Work/edition and proof changes invalidate prior approval. These boundaries
are covered by
[relationship review provenance](../../tests/unit/modules/knowledge/test_relationship_review_provenance.py).
